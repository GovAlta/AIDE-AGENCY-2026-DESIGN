## Formats

| File | What it is |
|---|---|
| `<name>.svg` | Full vector. Every shape and letter is an outlined path, so it opens anywhere and needs no fonts |
| `<name>.editable.svg` | The same, with the text as live, editable text in its matched font |
| `<name>.ai` | Adobe Illustrator (PDF-compatible `.ai`); open or place it in Illustrator |
| `<name>.png` | Raster preview, 1600 × 1600 |

The Alberta logo in these files is the official vector artwork from the VSAI asset library, not a trace. The main card was built from the
Monday vector: the same circuit artwork, microchip and logo, with the event text replaced to match the reference layout.

## Fonts in the invites

VSAI's font matcher identified the invite text as **Liberation Sans** Bold (title, date, cities) and Regular (the "Anchored by" lines),
with a match of 0.92 to 0.95 on the title. Liberation Sans is metric-compatible with Arial, so in the editable SVG, Arial Bold is a drop-in
substitute if Liberation Sans is not installed.

The design system sets all new media in **Inter**, the font of the MVAI video kit and the Contact Alberta handout. Keep the invites as they
are, and set new text in Inter.
